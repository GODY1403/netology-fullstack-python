# netology-fullstack-python

Репозиторий для домашних заданий и учебных проектов курса «Фулстек-разработчик на Python» от Нетологии.

## Организация домашних заданий

- Каждое домашнее задание хранится в отдельной папке с понятным названием, отражающим тему задания.
- Папки создаются по мере получения заданий, когда известны их условия и структура курса.
- В папке задания размещаются решение и необходимые для него файлы. При необходимости добавляется README.md с описанием и инструкциями по запуску и проверке.
- Изменения по одному заданию не должны затрагивать другие задания без необходимости.

Общие правила работы с репозиторием описаны в [AGENTS.md](AGENTS.md).
