# Правила работы с репозиторием

Эти правила применяются ко всем домашним заданиям и учебным проектам в репозитории.

- Строго следовать условиям задания.
- Писать простой, понятный и рабочий код.
- Не добавлять лишние зависимости и функции.
- Проверять решение перед сдачей.
- Не менять файлы других домашних заданий без необходимости.
- Сохранять каждое задание в отдельной папке с понятным названием.
- Не включать пароли, токены и конфиденциальные данные в коммиты.
- Создавать папки заданий по мере получения их условий. Не создавать пустые папки, пока неизвестна структура курса.
